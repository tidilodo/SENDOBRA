# Operação
1. Abrir URL privada e autenticar como proprietário.
2. Cadastrar obra, categoria, fornecedor e lançamento real.
3. Comprovantes são enviados no lançamento; baixar em Comprovantes.
4. Revisar auditoria. CSV respeita filtros.
5. Revogar usuário pelo botão desativar. Compartilhamento Sites continua uma barreira independente.
Backup: CSV é exportação operacional, não backup completo. Definir exportação D1 e R2 com retenção antes do piloto. Não afirmar restauração testada. Manter fonte e migrations versionados. Em falha, preservar dados, consultar deployment Sites e logs sanitizados; não reiniciar banco ou repetir migrations aplicadas. Para WhatsApp, contratar/configurar adaptador externo somente após decisão técnica, orçamento e teste de grupo dedicado.
